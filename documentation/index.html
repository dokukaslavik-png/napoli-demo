Getting started

This is a static HTML template — no build tools, no database, no server-side code.

  • Open index.html in any browser to preview it locally.
  • To publish, upload all files to any web host (shared hosting via FTP, Netlify, GitHub Pages, etc.). Keep the folder structure intact.

File structure

napoli/
├── index.html          Main page
├── 404.html            Error page
├── css/
│   └── style.css       All styles
├── js/
│   └── main.js         Menu rendering, nav, form, animations
├── images/             Images + favicon
└── documentation/      This guide
Note: the spinning pizza in the hero is a hand-drawn SVG (no image needed). Photos are used in the “About” and “Gallery” sections only.

Changing colors

All colors live at the top of css/style.css, inside :root { }:

--paper: #FBF4E9;   /* page background */
--ink:   #241612;   /* main text */
--red:   #D83A2B;   /* brand: hero, buttons, prices */
--gold:  #F4C542;   /* highlight */
--green: #4C7A34;   /* basil accent (tags) */

Change a value and the whole site updates.

Editing the menu

The menu is a simple list — no coding needed. Open js/main.js and find the MENU block near the top. Each item is one line:

{ name:'Margherita', desc:'Tomato, mozzarella, basil', price:12 },

Add or remove lines and categories freely. tag is optional and can be 'spicy', 'veg' or 'chef' (each shows a colored label). Change the currency with the CURRENCY variable.

Replacing images

Placeholder images are in the images/ folder (about.jpg, gallery-1.jpg … gallery-5.jpg). Replace them with your own photos using the same file names, or update the src paths in index.html.

Tip: free, commercial-use photos are available at Unsplash and Pexels. Use your own images or properly licensed ones before publishing.

Fonts

Two Google Fonts, loaded via a link in the <head>: Anton (headings) and Manrope (body). To change them, swap the Google Fonts link and update --font-display / --font-body in style.css.

Reservation form

The booking form works with the free Formspree service (no backend needed):

  • Create a free Formspree account and a new form.
  • Copy your form URL (looks like https://formspree.io/f/abc123).
  • In index.html, replace YOUR_FORM_ID in the form's action attribute with your URL.

Contacts & map

Edit the address, hours, phone and email in the “Contact” block of index.html. For the map, replace ?q=Vinnytsia+Soborna+1 in the map iframe URL with your own address.
